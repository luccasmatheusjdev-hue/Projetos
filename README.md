Proejto 1

Projeto de Gestão Financeira

Primeiro projeto de gestão financeira desenvolvido com o auxílio do Windsurf e ferramentas de Inteligência Artificial.
O sistema foi criado a partir de pesquisas, referências em outros aplicativos e modelos de planilhas de controle financeiro.

A estrutura do projeto foi construída de forma simples e prática, mesmo sem experiência prévia em desenvolvimento, utilizando IA para orientar decisões sobre organização, funcionalidades e arquitetura do aplicativo.

Objetivo

Criar uma aplicação de gestão financeira intuitiva, leve e funcional, focada em facilitar o controle financeiro pessoal.

Tecnologias e Desenvolvimento
Desenvolvimento assistido por IA
Estrutura planejada com foco em simplicidade
Referências baseadas em aplicativos e planilhas financeiras
Projeto preparado para conversão em APK
Status do Projeto

✅ Estrutura principal finalizada
✅ Interface funcional
✅ Organização financeira implementada
🚀 Pronto para gerar versão APK

Observações

Este projeto representa uma etapa importante de aprendizado e evolução no desenvolvimento de aplicações, demonstrando como ferramentas de IA podem acelerar a criação de soluções mesmo para iniciantes.
